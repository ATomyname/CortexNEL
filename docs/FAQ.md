# 常见问题

## 进服卡在 AUTH，或客户端启动后立刻退出

先看「系统设置」里的客户端路径与 Java 版本是否与实际安装一致。日志面板会给出具体失败阶段：`AUTH` 卡住通常是账号 token 或网关鉴权问题，客户端秒退通常是 Java 版本或客户端目录不对。

## 提示协议版本不匹配

目标服务器必须与客户端协议版本一致。CortexNEL 不做跨大版本转译，选错版本进不去是预期行为。服务器详情页会显示它要求的版本。

## 局域网共享怎么用

在「系统设置」里开启局域网共享，代理会监听 `0.0.0.0`，同网段的其他人用你的内网 IP + 端口连进来。首次开启需要在 Windows 防火墙放行，设置页有一键配置入口。

## 账号凭据存在哪

默认只保留在当前进程内存里，关闭即销毁。可在设置页显式开启「账号加密落盘」——开启后用 Windows DPAPI 按当前系统用户加密存到 `%AppData%\CortexNEL`，用于会话过期后的静默重登。开启与否随时可切换，关闭时会清除已落盘的凭据。

## 换机器 / 重装系统后账号要重登吗

落盘的凭据用 DPAPI 按 Windows 用户加密，换用户或重装系统后无法解密，需要重新登录。

## 支持基岩版（手机版）吗

不支持。基岩版服务器在列表里可见并标注为「基岩版」，但本仓库只实现 Java 线的进服。

## 为什么客户端不是我平时那个

启动器按服生成独立的运行沙盒（mods、config、options.txt 分层叠加），你原本的客户端目录不会被修改。这是有意设计：会话期不写原目录，也不向进程注入任何东西。

## 杀软报毒

混淆构建的产物会被部分引擎误判。用未混淆构建或自行从源码编译，见 [BUILDING.md](BUILDING.md)。
